# Chisel — Block Variety Mod

[![Download Latest](https://img.shields.io/github/v/release/BlueTellerAnger/chisel-decorative-blocks-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/BlueTellerAnger/chisel-decorative-blocks-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Use a Chisel to transform blocks into dozens of visual variants for detailed decorative building.

## Features

- Chisel tool transforms blocks into many visual variants
- Hundreds of alternate textures for stone, brick, and more
- In-game interface shows all available variants
- CraftTweaker integration to add custom chisel recipes
- Works with Chisel & Bits for sub-block detailing

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
